\chapter{Introduction}

Welcome to \textbf{WIZARDS}.

This document demonstrates the formatting features available in the
WIZARDS document class. It serves both as a reference and as a
regression test while developing the template.

\begin{Lore}[What is WIZARDS?]
WIZARDS is a custom tabletop role-playing game focused on collaborative
spellcraft, experimentation, and emergent magical systems rather than
predefined spell lists.
\end{Lore}

\section{Core Resolution}

Whenever an action has an uncertain outcome, the GM may call for a roll.

\begin{Rule}[Basic Check]
Roll 1d20 and add the appropriate modifier. If the total equals or
exceeds the target difficulty, the action succeeds.
\end{Rule}

\begin{Example}
A character with +3 Arcana attempts to decipher an ancient rune.

The GM sets the difficulty at 15.

Rolling a 14 produces a total of 17, so the attempt succeeds.
\end{Example}

\begin{OptionalRule}
Instead of fixed target numbers, the GM may roll an opposing check.
\end{OptionalRule}
