\section{Weapons}
\textit{Weapons} can be used by any character.

\vspace{0.4em}

If a character does not meet the W.I.Z.A.R.D.S. requirement for a weapon they are using, 
they lose Advantage twice on all actions made using that weapon.

\vspace{0.4em}

If a weapon's Storage Class is \textit{Attach}, then it can only be stored using an attachment point.

\vspace{0.4em}

If a weapon's Storage Class is ``N/A'', then it cannot be stored in inventory and must remain equipped.

\vspace{0.4em}

Weapon profiles can be found in Appendix E. %: Weapons.


\subsection{Weapon Attacks}
All physical weapons have an intrinsic \textit{Attack} ability.
This uses the process described by the Core Ability Attack, 
and use the range and damage specified in the weapon profile.

\vspace{0.4em}

Weapons that require \textit{Ammunition} must first be \textit{Loaded} with one of the 
specified ammunition types in order to use the Attack ability.

\vspace{0.4em}

The character may use an Action to retrieve the ammunition from storage and load the weapon.

The ammunition is expended when the attack is used.


\subsection{Archery \& Arrows}
Archery weapons require \textit{Arrow} ammunition. 

The base arrow deals \Roll{1d8} Piercing damage.

\vspace{0.4em}

Up to 20 arrows together have a Storage Class of Large.

\subsection{Mana Focus}
A character equipped with a \textit{Mana Focus} may spend Mana to cast spells.

\vspace{0.4em}

The \textit{Range} value limits the \textbf{maximum} range for spells cast using the focus.
If the range is ``N/A", the spell is only limited by its own range.

\vspace{0.4em}

The \textit{Damage} value is the default spell damage die used for spells cast using the focus.
If a spell does not specify the die class used for the spell damage (i.e., 1dD),
then the spell uses this die type.




\section{Jewelry}
\textit{Jewelry} is wearable equipment that provides opportunities for enchantment in 
addition to armor and weapons.
Unlike armor and weapons, jewelry is created with enchanting gems intact. 

(See Enchanting in Chapter 6: Skills.)

\vspace{0.4em}

Each standard piece of jewelry may accept up to one enchantment.


\subsection{Amulets}
An \textit{Amulet} is a pendant worn around the neck.
You may wear up to 1 amulet regardless of your armor.

\vspace{0.4em}

Amulets may have up to 3 gems.


\subsection{Circlets}
A \textit{Circlet} is a crown or tiara worn upon the head.
You may wear up to 1 circlet if the Armor Class for your Helm is Unarmored.

\vspace{0.4em}

Circlets may have up to 5 gems.


\subsection{Rings}
A \textit{Ring} is a band worn upon the finger of one hand.
You may wear up to 2 rings if the Armor Class for your Hands is Unarmored or Light.

\vspace{0.4em}

Rings may have up to 1 gem.
