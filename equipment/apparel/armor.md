
# Armor
Each piece of armor has an **Armor Type** `Head / Chest / Hands / Legs / Feet`
and an **Armor Class** `Unarmored / Light / Heavy`.

Only one piece of each Armor Type can be equipped.

-----

## Overall Armor Class
Your character's overall armor class is determined by the set of all armor you are wearing.

If 3+ slots are equipped with the same armor class, your overall armor class becomes that armor class.
Otherwise, your overall armor class is Light Armor.

|Class|Clash (d6) Save Modifier|Move Distance Modifier|
|-----|------------------------|------------------|
|Unarmored|`-1`|`+1"`|
|Light|`None`|`None`|
|Heavy|`+1`|`-1"`|

-----

## WIZARDS Penalty
Wearing armor penalizes a character's WIZARDS attributes according to the Type:

|Type|WIZARDS Attribute|
|----|-----------------|
|Head|Wisdom, Intelligence, Zest|
|Chest|Strength|
|Hands|Dexterity|
|Legs|Resilience|
|Feet|Agility|

The penalty is applied for each slot based on the Class of that armor:

|Class|Attribute Penalty|
|-----|-----------------|
|Unarmored|0|
|Light|-1|
|Heavy|-2|
